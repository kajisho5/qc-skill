# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, report it privately via GitHub's Security Advisories:

1. Go to the [Security tab](https://github.com/kajisho5/qc-skill/security) of this repository.
2. Click **Advisories** → **Report a vulnerability**.

This creates a private advisory visible only to the maintainers, where you
can share details and we can coordinate a fix and disclosure timeline.
